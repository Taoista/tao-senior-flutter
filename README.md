# Tao Senior Flutter

Skill pública de Codex para desarrollar aplicaciones Flutter con Clean Architecture, BLoC/Cubit, UX consistente, seguridad móvil y entornos reproducibles.

## Instalación

Copia este repositorio en tu directorio personal de skills:

```bash
git clone https://github.com/Taoista/tao-senior-flutter.git ~/.codex/skills/senior-flutter
```

Abre una conversación nueva en Codex para que detecte la skill.

## Contenido

- `SKILL.md`: instrucciones de la skill.

## Uso

Invoca la skill por su nombre, `senior-flutter`, o realiza una solicitud relacionada con su especialidad.
